## Como rodar

```
npm install --prefix api-gerenciamento-pedidos
npm start
```

Abrir http://localhost:3000

## Testes

```
npm test
```

## Rotas

- POST /pedidos
- GET /pedidos
- GET /pedidos/:id
- PATCH /pedidos/:id/status
- DELETE /pedidos/:id
